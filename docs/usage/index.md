# Utiliser Frigg

Frigg réunit la gestion d'une association dans une seule application : les
saisons et leurs tarifs, les fiches des membres, les adhésions et leurs
paiements, les événements et leurs inscriptions, et les e-mails aux
adhérents.

## Deux rôles

Chaque personne qui se connecte a un **compte**, avec l'un de ces deux rôles :

| Rôle | Ce qu'il permet |
| --- | --- |
| **Membre** | Gérer ses fiches (la sienne, celles de ses enfants…), demander une adhésion, payer, s'inscrire aux événements |
| **Administrateur** | Tout ce que peut faire un membre, plus la gestion de l'association : saisons, membres, adhésions, événements, communication, comptes et paramètres |

Chaque page de ce guide indique, sous son titre, le rôle requis pour les
actions qu'elle décrit.

::: tip Compte et fiche
Un **compte** permet de se connecter. Une **fiche de membre** décrit une
personne de l'association. Un même compte peut gérer plusieurs fiches (un
parent et ses enfants), et une fiche peut exister sans compte (un membre
enregistré par un administrateur).
:::

## Se repérer dans l'application

L'écran est le même pour tous : une barre latérale à gauche (repliable en
icônes sur grand écran, en surimpression sur téléphone), un fil d'Ariane, et
le contenu de la page. La barre latérale ne montre que les rubriques
autorisées pour votre rôle.

**Espace membre** : *Accueil*, *Mes membres*, *Adhésions*, *Événements à
venir*, *Mes inscriptions*, *À régler*.

**Espace administration** (administrateurs seulement) : *Tableau de bord*,
*Membres*, *Adhésions*, *Événements*, *Inscriptions*, *Communication*, puis,
dans *Configuration*, *Saisons*, *Comptes* et *Paramètres*.

Les administrateurs passent d'un espace à l'autre avec le sélecteur
« Administration / Membre » de la barre latérale ; le dernier choix est
mémorisé sur l'appareil.

## Par où commencer

Pour un nouvel administrateur, l'ordre habituel est :

1. renseigner les [paramètres de l'association](./settings) ;
2. créer la première [saison](./seasons) et ses [tarifs](./fees) ;
3. enregistrer ou [importer](./member-import) les [membres](./members) ;
4. ouvrir la saison pour recevoir les [adhésions](./memberships) ;
5. [inviter](./admin-accounts) les membres à créer leur compte.
