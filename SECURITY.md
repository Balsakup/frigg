# Politique de sécurité

## Versions prises en charge

Seule la dernière version stable de Frigg reçoit des correctifs de sécurité.
Mettez à jour vers la dernière release avant de signaler un problème.

## Signaler une vulnérabilité

**N'ouvrez pas d'issue publique pour une vulnérabilité.**

Signalez-la en privé depuis l'onglet
[Security › Report a vulnerability](https://github.com/Balsakup/frigg/security/advisories/new)
du dépôt. Indiquez si possible :

- la version concernée (étiquette de l'image ou de la release) ;
- les étapes pour reproduire le problème ;
- l'impact estimé (données exposées, élévation de privilèges…).

Vous recevrez un accusé de réception sous 7 jours. Le correctif est préparé
dans un avis de sécurité privé, puis publié avec une release ; vous serez
crédité dans l'avis si vous le souhaitez.
